# Fiber Coverage Simulation

An interactive Power BI dashboard that uses synthetic data to explore fiber coverage across 13 regions.

## Dashboard Overview

- Tracks coverage rate, eligible homes, covered homes, uncovered homes, and active subscriptions.
- Ranks regions by the number of homes without fiber coverage.
- Uses an interactive map to compare coverage rates by region.

## Tools

- Excel and Power Query for data preparation and validation
- Power BI for dashboard design and visualization
